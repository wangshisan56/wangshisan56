## 这个项目在做什么

这个站的目标不是替代官方，而是把中文用户最容易卡住的几个问题讲清楚：

- 从哪里开始下载
- 去哪里找 XChat 相关群组和主题入口
- 先准备什么，再做什么
- 为什么有人装好了还是进不去
- 问题到底是入口、账号还是连接环境
